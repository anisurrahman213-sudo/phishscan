সন্দেহজনক **লিংক, ইমেইল, ছবি/QR কোড, PDF, Word/Excel, APK, ZIP, HTML বা SVG** দিলে PhishScan বলে দেয়:

| প্রশ্ন | PhishScan যা দেখায় |
|---|---|
| **কী** ধরনের আক্রমণ? | ক্রেডেনশিয়াল চুরি, OTP/বিকাশ প্রতারণা, ম্যালওয়্যার, ClickFix, কুইশিং, ক্রিপ্টো ড্রেইনার ইত্যাদি ১২ ধরন |
| **কেন** করছে? | প্রতিটি ধরনের উদ্দেশ্য |
| **কীভাবে** করছে? | প্রতিটি লক্ষণ ও প্রমাণ: নকল ডোমেইন, ফর্ম, লুকানো কোড, রিডাইরেক্ট |
| **কোথা থেকে** চলছে? | IP, দেশ, শহর, হোস্টিং কোম্পানি, ডোমেইন কবে কেনা, ইমেইল কোন সার্ভার থেকে এসেছে |
| তথ্য **কোথায় যায়**? | ফর্মের গন্তব্য, Telegram বট, Discord webhook ইত্যাদি |
| **কী ক্ষতি** করতে পারে? | প্রতিটি আক্রমণের সম্ভাব্য পরিণতি |
| **একই প্রতারকের আর কোন সাইট?** | crt.sh দিয়ে লুকানো সাবডোমেইন আর একই ব্র্যান্ড নকল করা অন্য ডোমেইন |
| **একই দল কিনা?** | ক্যাম্পেইন ফিঙ্গারপ্রিন্ট — একাধিক ফিশিং একই উৎস থেকে কিনা মেলায় |
| **কাকে রিপোর্ট** করবেন? | হোস্টিং ও রেজিস্ট্রারের abuse ইমেইল, আর বাংলাদেশের সংস্থা |

বাংলায় রিপোর্ট দেয়, বাংলাদেশের প্রেক্ষাপট মাথায় রেখে বানানো (বিকাশ, নগদ, ব্যাংক, OTP প্রতারণা)।

> ⚠️ **শুধু প্রতিরক্ষা, গবেষণা ও সচেতনতার জন্য।** টুলটা কোনো ফাইল রান করে না, কোনো ফর্ম সাবমিট করে না, কারো সিস্টেমে ঢোকে না।

## ⚖️ সৎ সীমাবদ্ধতা (আগে পড়ুন)

কোনো ফিশিং ডিটেক্টর **১০০% নির্ভুল হতে পারে না**, এটাও না। নতুন কৌশল প্রতিদিন আসে।

- **স্কোর কম মানে "নিরাপদ" প্রমাণিত নয়।** একদম নতুন ফিশিং অনেক সময় কোনো ডেটাবেসে থাকে না।
- **স্কোর বেশি মানে ১০০% ফিশিং নয়।** মাঝে মাঝে আসল সাইটও সন্দেহজনক দেখাতে পারে। প্রমাণগুলো নিজে পড়ে সিদ্ধান্ত নিন।
- **লোকেশন হলো সার্ভারের, প্রতারকের বাসার নয়।** প্রতারকরা VPN, Cloudflare, হ্যাক করা সাইট ব্যবহার করে।
- **আসল ব্যক্তির পরিচয় শুধু পুলিশ** আইনি প্রক্রিয়ায় হোস্টিং, টেলিকম বা বিকাশ/নগদ থেকে বের করতে পারে। এই টুলের রিপোর্ট সেখানে প্রমাণ হিসেবে কাজে লাগবে।
- ফোন কল (ভিশিং) আর ডিপফেক এই টুল দিয়ে ধরা যায় না।

## 📦 ইনস্টল

> 🆕 নতুন? ধাপে ধাপে **[SETUP.md](SETUP.md)** অনুসরণ করুন (clone → ইনস্টল → যাচাই → চালান)।

চারটা উপায় আছে, যেকোনো একটা বেছে নিন।

### ক) ইনস্টলার স্ক্রিপ্ট (Kali / Ubuntu / Debian), নতুনদের জন্য প্রস্তাবিত
```bash
git clone https://github.com/YOUR-USERNAME/phishscan.git
cd phishscan
chmod +x install.sh
./install.sh            # sudo দিয়ে চালাবেন না, দরকার হলে নিজেই পাসওয়ার্ড চাইবে
phishscan --version     # "PhishScan 3.1.0" দেখালে সফল
```
সিস্টেম টুল (whois, exiftool, zbar) আর সব ঐচ্ছিক প্যাকেজ নিজেই বসায়। সরাতে চাইলে: `./install.sh --uninstall`

### খ) pipx (যেকোনো Linux/macOS, সবচেয়ে পরিষ্কার)
```bash
sudo apt install pipx && pipx ensurepath        # macOS: brew install pipx
pipx install "git+https://github.com/YOUR-USERNAME/phishscan.git"
pipx inject phishscan pillow pyzbar oletools extract-msg androguard   # ঐচ্ছিক
```

### গ) pip (Python 3.9+)
```bash
pip install "phishscan[full] @ git+https://github.com/YOUR-USERNAME/phishscan.git"
```
> Kali-তে pip "externally-managed-environment" ত্রুটি দিলে উপায় ক বা খ ব্যবহার করুন।

### ঘ) Docker (সবচেয়ে নিরাপদ, আলাদা কন্টেইনারে চলে)
```bash
git clone https://github.com/anisurrahman213-sudo/phishscan.git && cd phishscan
docker build -t phishscan .
docker run --rm phishscan "hxxps://bad-site[.]top/login"
docker run --rm -v "$PWD:/data" phishscan mail.eml                  # বর্তমান ফোল্ডারের ফাইল
docker run --rm -e VT_API_KEY -e URLSCAN_API_KEY phishscan "URL"     # API key সহ
```
কন্টেইনারে root ছাড়া একজন সাধারণ ব্যবহারকারী হিসেবে চলে। রিপোর্ট পেতে `-v "$PWD:/data"` দিন, তাহলে `phishscan_evidence/` আপনার ফোল্ডারে তৈরি হবে।

### কোন প্যাকেজ কী কাজে লাগে

| প্যাকেজ | না থাকলে যা হবে |
|---|---|
| `requests` (আবশ্যক) | অনলাইন কিছুই কাজ করবে না (`--offline` চলবে) |
| `pillow` + `pyzbar` + `zbar-tools` | ছবির QR কোড পড়বে না |
| `exiftool` | ছবির মেটাডেটা কম আসবে |
| `oletools` | ম্যাক্রোর বিস্তারিত পাবেন না (শুধু "ম্যাক্রো আছে" দেখাবে) |
| `androguard` | APK-র প্যাকেজের নাম পাবেন না (অনুমতি তবুও দেখাবে) |
| `extract-msg` | Outlook `.msg` পড়বে না (`.eml` হিসেবে সেভ করে দিন) |
| `whois` | `.bd` সহ কিছু ডোমেইনের তথ্য কম আসবে |
| `chromium` | `--screenshot` কাজ করবে না |

## 🔑 API key (ঐচ্ছিক, ফ্রি)

Key ছাড়াও টুল পুরোপুরি চলে। key দিলে বিশ্বের নিরাপত্তা গবেষকদের আগের রেকর্ডও রিপোর্টে যোগ হয়।

| সেবা | কী যোগ হয় | key নেওয়ার লিংক |
|---|---|---|
| VirusTotal | কয়টি অ্যান্টিভাইরাস ক্ষতিকর বলেছে, ম্যালওয়্যারের নাম | https://www.virustotal.com/gui/my-apikey |
| urlscan.io | আগের স্ক্যান, স্ক্রিনশট লিংক, ক্ষতিকর চিহ্নিত কিনা | https://urlscan.io/user/profile/ |

> urlscan.io-তে "Your account is too new" দেখালে কয়েক দিন পর আবার চেষ্টা করুন। নতুন অ্যাকাউন্টে এটা স্বাভাবিক।

**বসানো (zsh, Kali-র ডিফল্ট):**
```bash
echo 'export VT_API_KEY="আপনার_key"' >> ~/.zshrc
echo 'export URLSCAN_API_KEY="আপনার_key"' >> ~/.zshrc
source ~/.zshrc
```
bash ব্যবহার করলে `~/.zshrc`-এর জায়গায় `~/.bashrc` লিখুন।

> 🔒 **key কখনো GitHub-এ কমিট করবেন না**, কাউকে পাঠাবেন না। কোডে key লেখা নেই, শুধু environment variable থেকে পড়ে।
> VirusTotal ফ্রি সীমা: মিনিটে ৪টি, দিনে ৫০০টি। টুল নিজেই অপেক্ষা করে সীমা মেনে চলে।

## 🚀 ব্যবহার

### ইন্টার‍্যাক্টিভ মোড (সবচেয়ে সহজ — পেস্ট করুন, হয়ে যাবে)
কোনো আর্গুমেন্ট ছাড়া চালান, তারপর একের পর এক লিংক বা ফাইল পেস্ট করতে থাকুন — প্রতিবার নতুন কমান্ড লেখার দরকার নেই:
```bash
phishscan                 # ইনস্টল করা থাকলে
./phishscan.sh            # ইনস্টল ছাড়াই রিপো থেকে
```
```
phishscan> hxxps://bkash-verify[.]top/pin      ← লিংক পেস্ট করুন (ডিফ্যাং করাও চলে)
phishscan> /home/kali/Downloads/invoice.pdf    ← অথবা ফাইলের পাথ (অনেক টার্মিনালে টেনে এনে ছাড়লেই বসে)
phishscan> quit
```
যেকোনো লিংক বা ফাইল নেয় — `.eml .msg .pdf .docx .xlsx .csv .txt .apk .zip .png .jpg .html ...` — আর প্রতিটির ওপর তথ্য সংগ্রহ করে। প্রথম লিংকে একবার জিজ্ঞাসা করে সাইটে সরাসরি ঢুকবে (সম্পূর্ণ তথ্য, VM-এ চালানো ভালো) নাকি নিরাপদ মোডে থাকবে। ফাইল সবসময় নিরাপদে বিশ্লেষণ হয়।

পাইপও চলে:
```bash
echo "hxxps://bad[.]top/login" | phishscan
cat links.txt | phishscan                      # প্রতি লাইনে একটি লিংক
```

### একটি স্ক্যান

```bash
phishscan "<লিংক বা ফাইল>" [অপশন]
```

| কাজ | কমান্ড |
|---|---|
| লিংক পরীক্ষা | `phishscan "https://bkash-verify.top/login"` |
| ডিফ্যাং করা লিংক (নিরাপদে শেয়ার করা) | `phishscan "hxxps://bkash-verify[.]top/login"` |
| সাইটে না ঢুকে (প্যাসিভ) | `phishscan "URL" --no-fetch` |
| ইমেইল | `phishscan mail.eml` |
| Outlook ইমেইল | `phishscan mail.msg` |
| QR কোডের ছবি / স্ক্রিনশট | `phishscan qr.jpg` |
| PDF / Word / Excel | `phishscan invoice.pdf` |
| Android অ্যাপ | `phishscan update.apk` |
| ZIP / HTML / SVG অ্যাটাচমেন্ট | `phishscan file.zip` |
| অনেক লিংক একসাথে | `phishscan links.txt` (প্রতি লাইনে একটি, `#` দিয়ে মন্তব্য) |
| স্ক্রিনশট সহ (শুধু VM-এ!) | `phishscan "URL" --screenshot` |
| ইন্টারনেট ছাড়া | `phishscan file.pdf --offline` |
| শুধু সংক্ষিপ্ত ফলাফল | `phishscan "URL" --quiet` |

### সব অপশন

| অপশন | কাজ |
|---|---|
| `--no-fetch` | ফিশিং সাইটে সংযোগ করবে না। শুধু DNS, WHOIS, লোকেশন আর রেপুটেশন দেখবে |
| `--offline` | কোনো ইন্টারনেট নয়, শুধু ফাইল বা লিংকের নিজস্ব বিশ্লেষণ |
| `--screenshot` | headless Chromium দিয়ে পেজের ছবি তোলে (পেজের JS চলে, তাই শুধু VM-এ) |
| `--json FILE` / `--html FILE` | রিপোর্ট নির্দিষ্ট জায়গায় সেভ |
| `--evidence DIR` | প্রমাণ ফোল্ডার (ডিফল্ট `phishscan_evidence/`) |
| `--max-links N` | ইমেইল বা PDF থেকে সর্বোচ্চ কয়টি লিংক দেখবে (ডিফল্ট ১০) |
| `--vt-max N` | প্রতি স্ক্যানে সর্বোচ্চ VirusTotal কল (ডিফল্ট ৮) |
| `--brands FILE` | অতিরিক্ত ব্র্যান্ডের JSON ফাইল (নিচে দেখুন) |
| `--no-related` | crt.sh দিয়ে সম্পর্কিত ডোমেইন খোঁজা বন্ধ রাখবে |
| `--quiet` | শুধু স্কোর ও ধরন |
| `--doctor` | সেটআপ ঠিক আছে কিনা নিজে যাচাই করে |
| `--version` | ভার্সন |

### তিনটি মোডের পার্থক্য

| মোড | ফিশিং সাইটে সংযোগ | ইন্টারনেট | কখন |
|---|---|---|---|
| সাধারণ | হ্যাঁ | হ্যাঁ | সবচেয়ে বিস্তারিত ফল, VM-এ চালান |
| `--no-fetch` | না (শুধু DNS) | হ্যাঁ | প্রতারককে না জানিয়ে দেখতে চাইলে |
| `--offline` | না | না | ফাইল বিশ্লেষণ, ইন্টারনেট না থাকলে |

## 🏦 নিজের ব্যাংক/প্রতিষ্ঠান যোগ করা (কনফিগ)

PhishScan-এ বিকাশ, নগদ, প্রধান ব্যাংক, Facebook, Google ইত্যাদি আগে থেকেই আছে। নিজের ব্যাংক, বিশ্ববিদ্যালয় বা কোম্পানি যোগ করতে **কোড বদলানোর দরকার নেই**:

```bash
mkdir -p ~/.config/phishscan
cp config/brands.example.json ~/.config/phishscan/brands.json
nano ~/.config/phishscan/brands.json
```
```json
{
  "shapnobank": ["shapnobank.com.bd"],
  "mycompany": ["mycompany.com", "mycompany-mail.com"]
}
```
- বাম পাশে ব্র্যান্ডের নাম (ছোট হাতের অক্ষরে, ফিশিং লিংকে যে নামে আসে), ডান পাশে **আসল** ডোমেইনগুলোর তালিকা
- এরপর `shapnobank-login.top`-এর মতো নকল ডোমেইন ধরা পড়বে, আর `shapnobank.com.bd` নিরাপদ গণ্য হবে
- এক স্ক্যানের জন্য: `phishscan URL --brands myfile.json`
- অন্য জায়গায় রাখতে: `export PHISHSCAN_BRANDS=/path/to/brands.json`

## 🐍 Python লাইব্রেরি হিসেবে

নিজের প্রোগ্রাম, বট বা ওয়েবসাইটে ব্যবহার করতে:
```python
from phishscan import scan

r = scan("hxxps://bkash-verify[.]top/pin", offline=True)
print(r["score"], r["verdict"])               # 44 খুব সন্দেহজনক

    print(t["name"], "—", t["impact"])
for f in r["findings"]:
    print(f["severity"], f["message"])

r = scan("/path/to/mail.eml")                 # ফাইলও চলে
```
ফেরত আসা dict-এর গঠন CLI-এর `report.json`-এর মতোই।

## 🔍 একই প্রতারকের অন্যান্য সাইট খোঁজা (crt.sh)

প্রতারকের **আসল পরিচয়** বের করা যায় না (সেটা শুধু পুলিশ পারে), কিন্তু তার **বাকি ফাঁদগুলো** বের করা যায়। PhishScan স্বয়ংক্রিয়ভাবে Certificate Transparency (crt.sh) ঘেঁটে দেখে, কোনো API key বা টাকা লাগে না:

- **লুকানো সাবডোমেইন:** একই ডোমেইনে `login.`, `admin.`, `panel.`, `otp.`-এর মতো যত পেজ আছে
- **একই ব্র্যান্ড নকল করা অন্য ডোমেইন:** যেমন বিকাশ নকল করা একটা সাইট পেলে, crt.sh থেকে বিকাশ নকল করা **আরও** ডোমেইন খুঁজে দেয়

কাজে লাগে দুইভাবে: লুকানো লগইন পেজ ধরা পড়ে, আর একই দলের সব সাইট **একসাথে** রিপোর্ট করে বন্ধ করানো যায়। বন্ধ রাখতে: `--no-related`।

## 🧬 ক্যাম্পেইন ফিঙ্গারপ্রিন্ট — একই দল কিনা চেনা

চুরি করা তথ্য **কোথায় যায়** (Telegram বট, exfil সার্ভার, ওয়ালেট) আর **কে হোস্ট করছে**, তা মিলিয়ে PhishScan একটা ছোট আইডি বানায়। **একই আইডি = সম্ভবত একই প্রতারক দল বা একই ফিশিং কিট।** বিভিন্ন ফিশিং আলাদা স্ক্যান করে আইডি মিলিয়ে দেখলে বোঝা যায় সেগুলো একই উৎস থেকে কিনা, যা পুলিশের একটা মামলায় অনেকগুলো ঘটনা জোড়া দিতে সাহায্য করে। (অফলাইনেও কাজ করে; Telegram টোকেন ফাঁস হয় না।)

## 🧯 নিরাপদে কাজ করার নিয়ম

1. **সাধারণ মোড আর `--screenshot` শুধু আলাদা VM-এ চালান** (VirtualBox/VMware-এ Kali)। কাজ শেষে snapshot-এ ফিরিয়ে নিন।
2. **কোনো সন্দেহজনক ফাইল রান করবেন না।** টুলও কখনো রান করে না।
3. **ফিশিং পেজে আসল তথ্য দেবেন না**, পরীক্ষার জন্যও না।
4. প্রথমে `--no-fetch` দিয়ে দেখুন, তারপর দরকার হলে সাধারণ মোড।
5. সক্রিয় স্ক্যানে ফিশিং সার্ভার আপনার IP দেখতে পায়। গোপনীয়তা চাইলে VM-এ VPN ব্যবহার করুন। তবে কিছু ফিশিং সাইট VPN দেখলে ব্লক করে (cloaking), তখন রিপোর্টে সেটা লেখা থাকবে।
6. `phishscan_evidence/` ফোল্ডারে আসল ফিশিং লিংক আর ব্যক্তিগত ইমেইল থাকে, তাই **এটা GitHub-এ দেবেন না** (`.gitignore`-এ বাদ দেওয়া আছে)।

### ⚠️ তথ্য বা টাকা দিয়ে ফেললে সঙ্গে সঙ্গে
1. **ব্যাংক বা বিকাশ/নগদ হেল্পলাইনে ফোন** করে অ্যাকাউন্ট ব্লক বা ফ্রিজ করান
2. **পাসওয়ার্ড বদলান** (একই পাসওয়ার্ড যেখানে যেখানে ব্যবহার করেছেন, সব জায়গায়)
3. **সব ডিভাইস থেকে লগআউট** করুন, **2FA চালু** করুন (SMS-এর বদলে Authenticator অ্যাপ ভালো)
4. APK ইনস্টল করে থাকলে ফোন **ইন্টারনেট থেকে বিচ্ছিন্ন** করুন, অ্যাপ আনইনস্টল করুন, দরকার হলে ফ্যাক্টরি রিসেট
5. টুলের রিপোর্ট আর স্ক্রিনশট নিয়ে **থানা বা সাইবার ক্রাইম ইউনিটে** অভিযোগ করুন

## 🔧 সমস্যা সমাধান

| সমস্যা | কারণ ও সমাধান |
|---|---|
| `command not found: phishscan` | `./install.sh` চালান, অথবা রিপোজিটরির ভেতর থেকে `python3 -m phishscan ...` ব্যবহার করুন। pipx হলে `pipx ensurepath` দিয়ে টার্মিনাল রিস্টার্ট করুন |
| রিডাইরেক্ট চেইনে `[403]` | সাইট স্ক্যানার আটকাচ্ছে (cloaking)। টুল নিজেই মোবাইল হিসেবে আবার চেষ্টা করে। তবুও না হলে VPN বন্ধ করে চালান, বা `--screenshot` দিন |
| "Cloudflare বট-চেক" | পেজের ভেতরটা দেখা যায়নি। urlscan.io-র আগের স্ক্যান দেখুন, বা VM-এ `--screenshot` দিন |
| "VirusTotal key ভুল (HTTP 401/403)" | key আবার কপি করে বসান, `echo $VT_API_KEY` দিয়ে দেখুন |
| "ফ্রি সীমা শেষ (HTTP 429)" | এক মিনিট পর চালান, বা `--vt-max` কমান |
| urlscan "account is too new" | কয়েক দিন পর key বানান। ততদিন key ছাড়াও কাজ করে |
| QR কোড পড়ছে না | `sudo apt install zbar-tools libzbar0 && pip install pyzbar pillow` |
| `রিজলভ হয়নি` | সাইট বন্ধ হয়ে গেছে, বা DNS ব্লক। ডোমেইন তথ্য তবুও আসতে পারে |
| `--brands ফাইল সমস্যা` | JSON-এর বাইরে `{ }` থাকতে হবে, আর প্রতিটি মান হবে `["ডোমেইন"]` তালিকা। `python3 -m json.tool file.json` দিয়ে যাচাই করুন |
| বাংলা অক্ষর ভাঙা দেখায় | `sudo apt install fonts-noto-core fonts-beng`, টার্মিনাল রিস্টার্ট করুন |
| `externally-managed-environment` | `./install.sh` ব্যবহার করুন (আলাদা venv বানায়) |

## 🧪 টেস্ট ও ডেভেলপমেন্ট

```bash
pip install -e ".[dev,full]"
ruff check .                        # কোডের মান ও নিরাপত্তা নিয়ম
pytest -q --cov=phishscan           # ৮৬টি টেস্ট, ৮২% কভারেজ, ইন্টারনেট লাগে না
```

**কী কী টেস্ট হয়:**
- **ধরা পড়ছে কিনা:** ফিশিং ইমেইল, PDF, APK, ClickFix, ম্যাক্রো, ZIP, SVG, ক্রিপ্টো, হোমোগ্লিফ, টাইপোস্কোয়াট, Facebook রিডাইরেক্ট লিংক
- **ভুল সতর্কতা দিচ্ছে না তো:** Google, bKash, Wikipedia, GitHub, ample.com, officer.com, আসল ইমেইল, সাধারণ ছবি/PDF/HTML
- **অনলাইন অংশ:** লোকাল সার্ভারে রিডাইরেক্ট, meta-refresh, cloaking, ডাউনলোড; আর নকল উত্তর দিয়ে RDAP, IP লোকেশন, VirusTotal (ভুল key, সীমা শেষ, রেট লিমিট), urlscan.io
- **কাঠামো:** কনফিগ ফাইল, Python API, ভার্সন সামঞ্জস্য, HTML রিপোর্টে কোড ইনজেকশন বন্ধ

**প্রতিটি push-এ GitHub যা স্বয়ংক্রিয়ভাবে করে:**
| কাজ | কী যাচাই করে |
|---|---|
| CI → lint | ruff নিরাপত্তা ও মানের নিয়ম |
| CI → test | Python 3.9, 3.11, 3.12, 3.13-এ সব টেস্ট, কভারেজ ৭৫%-এর নিচে নামলে ব্যর্থ |
| CI → package | wheel বানিয়ে পরিষ্কার পরিবেশে ইনস্টল করে চালায় |
| CI → docker | Docker ইমেজ বানিয়ে চালায় |
| CodeQL | GitHub-এর নিরাপত্তা স্ক্যান (সাপ্তাহিক) |
| Dependabot | লাইব্রেরির নিরাপত্তা আপডেট (সাপ্তাহিক) |
| Release | `v3.0.1`-এর মতো ট্যাগ দিলে স্বয়ংক্রিয় রিলিজ |
